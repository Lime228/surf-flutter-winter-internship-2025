# Fruit App

## Описание приложения

Fruit App — это nutrition-tech приложение, которое помогает подбирать фрукты и создавать рецепты из избранных фруктов с учётом их пищевой ценности. 

Приложение позволяет:

- Просматривать список фруктов с фильтрацией по калориям, сахару и жирам.
- Добавлять\удалять фрукты в избранное.
- Создавать и удалять рецепты из избранных фруктов.
- Просматривать детальную информацию о каждом фрукте (семейство, порядок, род, калории, жиры, сахар, углеводы, белки).

---

## Структура приложения

Приложение построено по архитектуре MVVM с разделением на слои:

- **UI-экраны** (`screens/`):
    - `FruitListScreen` — список фруктов с поиском и фильтрами.
    - `FruitDetailScreen` — детали фрукта.
    - `FavoritesScreen` — список избранных фруктов.
    - `RecipesScreen` — список рецептов.
    - `CreateRecipeScreen` — создание нового рецепта.
    - `HomeScreen` — корневой экран с bottom navigation.

- **Модели** (`models/`):
    - `fruit.dart` — модель фрукта и его питательной ценности.
    - `recipe.dart` — модель рецепта (название, описание, список ID фруктов).

- **Сервисы** (`services/`):
    - `api_service.dart` — загрузка фруктов с API `fruityvice.com` с кэшированием в `SharedPreferences`.
    - `favorite_service.dart` — хранение и управление ID избранных фруктов.
    - `recipe_service.dart` — хранение и управление рецептами.

- **UI-компоненты и тема** (`theme/`):
    - `app_theme.dart` — кастомная светлая тема Material 3.
    - `filter_sheet.dart` — модальное bottom sheet с фильтрами и быстрыми пресетами («Завтрак», «Тренировка» и т.д.).

## Реализованные экраны

### Список фруктов (`FruitListScreen`)

- Загрузка списка фруктов с API `fruityvice.com` с отображением источника (сеть / кэш).
- Поиск по названию и семейству.
- Фильтрация по диапазону калорий, сахара и жиров.
- Сортировка: A–Z, Z–A, по калориям (возр./убыв.).
- Индикатор онлайн/оффлайн и кнопка обновления.
- Кнопка «Избранное» у каждого фрукта.

### Детали фрукта (`FruitDetailScreen`)

- Крупный заголовок с названием и семейством.
- Блок с информацией: семейство, порядок, род.
- Блок с питательной ценностью (на 100 г): калории, жиры, сахар, углеводы, белки.
- Кнопка «Добавить в избранное» в AppBar.

### Избранное (`FavoritesScreen`)

- Список фруктов, добавленных в избранное.
- Возможность удалить фрукт из избранного.
- Переход к деталям фрукта по клику.

### Рецепты (`RecipesScreen`)

- Список сохранённых рецептов.
- У каждого рецепта: название, описание, состав (список фруктов), суммарная калорийность и макронутриенты.
- Кнопка «Создать рецепт» и удаление рецепта через диалог.

### Создание рецепта (`CreateRecipeScreen`)

- Поле ввода названия и описания рецепта.
- Список только избранных фруктов с чекбоксами.
- Подсчёт выбранного количества фруктов.
- Валидация: название и хотя бы один фрукт обязательны.
- После сохранения рецепт добавляется в список.

## Ключевые функции

- **Избранное**
    - Фрукты добавляются/удаляются из избранного по ID.
    - Список избранных фруктов используется при создании рецептов.

- **Рецепты**
    - Рецепт хранит ID выбранных фруктов.
    - При отображении рецепта фрукты подтягиваются из общего списка.
    - Суммарная калорийность и макронутриенты рассчитываются автоматически.

- **Фильтры и пресеты**
    - Bottom sheet с ручными фильтрами (калории, сахар, жиры).
    - Быстрые пресеты: «Завтрак», «Тренировка», «Сытость», «Перекус», «Диета».

- **Сетевые и оффлайн-данные**
    - Приложение пытается загрузить фрукты из сети, при ошибке использует кэш.
    - При отсутствии интернета показывается баннер «Нет соединения».

## Технические детали

- **Стек**: Flutter (Dart), Material 3, `http`, `shared_preferences`, `connectivity_plus`.
- **Состояние**: управление состоянием через `StatefulWidget` и `setState`.
- **Хранение данных**:
    - Фрукты: кэш в `SharedPreferences` + API.
    - Избранное: набор ID в `SharedPreferences`.
    - Рецепты: список в `SharedPreferences`.
- **UI**:
    - Карточки, списки, bottom sheet, диалоги.
    - Кастомная тема с цветами, отступами и стилями.
    - Адаптивные отступы и радиусы углов.
